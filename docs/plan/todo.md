# 티켓팅 사이트 개발 계획서

## 1. 개발 목표

티켓팅 사이트의 공연 조회, 예매, 회원 기능을 단계적으로 개발한다.
페이지 개발은 **세부 페이지 우선 구현 → 메인 페이지 마지막 구현** 순서로 진행한다.

### 1.1 2026-05-29까지의 목표

* 이벤트 페이지 개발
* 공지사항 페이지 개발

---

## 2. 주요 협업 및 이벤트 요소

### 2.1 당근 협업

* 당근 협업 관련 콘텐츠 또는 프로모션 요소 반영
* 구체적인 노출 방식 및 콘텐츠는 추후 확정

### 2.2 이벤트 페이지

* 할인 이벤트를 보여주는 이벤트 페이지 개발
* 할인 공연 또는 프로모션 정보를 사용자에게 노출
* `2026-05-29`까지 우선 개발 대상에 포함

---

## 3. 공연 콘텐츠 구성

### 3.1 오픈예정

* 아직 예매가 시작되지 않은 **미래 공연 데이터**를 목록으로 노출
* 더미 데이터 약 20~30개 준비
* 스크롤 가능한 목록 형태로 구현

### 3.2 랭킹

* 현재 오픈 중인 공연 데이터를 대상으로 구성
* 구매율 또는 예매 건수가 높은 공연 순으로 정렬할지 검토
* 기본 정렬 기준은 **예매 개수**로 설정
* 더미 데이터 약 20~30개 준비
* 스크롤 가능한 목록 형태로 구현

### 3.3 공지사항

* 공연 또는 서비스 운영 관련 공지사항을 보여주는 페이지 개발
* 공지사항 목록 형태로 노출
* 공지사항 상세 내용 확인 기능은 필요 여부에 따라 추가 검토
* `2026-05-29`까지 우선 개발 대상에 포함

## 4. 회원 기능

### 4.1 회원가입

### 4.2 로그인

* 이메일 및 비밀번호 기반 자체 로그인 기능 개발
* 회원가입 UI 구현 이후 백엔드 연동 진행

### 4.3 회원 DB 항목

| ---- | ---------------- |
| 이름   | 사용자 이름           |
| 연락처  | 사용자 전화번호         |
| 이메일  | 로그인 및 회원 식별용 이메일 |
| 비밀번호 | 사용자 비밀번호         |
