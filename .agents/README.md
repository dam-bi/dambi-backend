# 기능 구현 에이전트 워크플로

기능 하나는 아래 순서로 처리한다.

```text
기능 요청
  -> planning-agent: 계획서 작성 및 검토
  -> implementation-agent: 실패 테스트 작성, 구현, 테스트 실행
  -> review-agent: 계획서·diff·테스트 결과 검토
  -> (필수 수정이 있으면 implementation-agent로 돌아감)
  -> 승인
```

## 인계 규칙

1. 계획 에이전트의 계획서가 검토·승인되기 전에는 구현을 시작하지 않는다.
2. 구현 에이전트는 계획서, 변경 diff, 테스트 결과를 리뷰 에이전트에 모두 전달한다.
3. 리뷰 에이전트가 `[필수]` 발견 사항을 남기면 구현 에이전트가 수정하고 같은 계획서를 기준으로 재검토한다.
4. 구현 범위가 바뀌면 계획 에이전트가 계획서를 먼저 갱신하고 다시 검토한다.
